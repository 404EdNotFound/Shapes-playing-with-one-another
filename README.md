# Shapes-playing-with-one-another
This is a project writen in Python under Pygame Module since this was made out of boredom. This consists of a group of shapes floating around an interface whilst colliding with other objects.

# Features
* Pygame Module initialised for creating the interface and placing objects that can be controlled
* Shape Class that is used for moving and collision of the shape
* Collision Logic based on Overlapping of each shape
* Shapes stored as objects in an Array and an iterative loop checking if one shape is colliding with another shape or within the sides of the screen.

# Running the Project
* This project is written with 2 Python Files (one for Procedural and one for OOP). Please ensure that you have Python installed and an IDE (VSCode, IDLE, Thonny etc) (prefably Python 3)
* Please also ensure that you have Pygame installed (after installing Python, and prefably to its latest version)
